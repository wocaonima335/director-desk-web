## 2. UI 流程（A1、A3）

- 布局：左侧镜头卡片列表、中间大预演画面、右侧当前镜头简易属性、底部任务进度。
- 视觉：深色中性背景、蓝强调色；镜头状态用文字加图标表达，不单靠颜色。状态词汇：待设计、生成中、检查失败、待确认、已批准、导出中、已交付、已过期。
- 模式：默认简易模式显示景别、角度、运镜、时长、人物动作与"保持不变"对象；坐标、曲线、完整时间轴与复杂效果折叠进高级模式。保留高级编辑入口，隐藏不等于删除。
- 动作区分：暂停后可恢复、取消当前步骤、撤销本镜头修改三者独立入口，不混用。
- 简易路径主流程（未实现按钮不得伪装可用，实际可用性由 005 起逐任务交付）：
  1. 启动桌面程序，打开示例或新建本地项目，选择存储目录。
  2. 选择"设计一个镜头"或"短段落自动预演"。
  3. 输入剧情、人物、场景与风格；系统列出缺失信息，不代填。
  4. 生成结构化镜头计划，展示时长、调度、机位与本次调用预算上限；mock 模式下界面明确标识"模拟模式"。
  5. 用户确认镜头计划（第一审批点），授权在对应草稿空间自动搭建与修复。
  6. 逐镜头运行，显示阶段、检查结果；检查不完整显示"不确定"，不伪装通过。
  7. 用户整体预览、局部修改或确认，进入导出确认（第二审批点）：选择输出目录与覆盖规则。
  8. 写盘校验成功后才显示"已交付"；失败可从失败镜头继续。
- 任务执行中锁定受影响工程写操作；超预算、角色/镜头数量变化、路径冲突时暂停确认。
- 本节为 UI 方向冻结，不表示功能已可用。本轮批准终点在 DSK-008：仅到计划审阅与可应用提案的独立预览；不含 DSK-009 的正式事务提交与镜头级修改任务撤销，也不含其后的导出执行。上述流程中导出及交付各步的实际可用性由对应任务逐项交付并验收。

## 3. 五套件、镜头范围与样例（A2）

五套件：双人对话、人物入场/离场、跟拍、推进/环绕、简单对峙。
硬边界：单镜头 5-15 秒、1-2 名主要人物、单连续机位、24fps、9:16 或 16:9；拆镜仅同场景 3-5 镜头、总长 15-75 秒。越界输入拒绝并提示边界。

### 样例 S1：完整单镜头（双人对话）

- 套件：双人对话；时长 8 秒；画幅 9:16；24fps；1 个连续机位。
- 人物 1：林夏，女，28 岁，齐肩短发，深灰风衣。
- 人物 2：陈默，男，32 岁，平头，蓝色工装外套。
- 环境：夜晚城市天台，混凝土护栏，背景为虚化的城市灯光，侧逆光。
- 动作：林夏递出 U 盘，陈默迟疑后接过；无大范围走位。
- 机位意图：中景过肩（林夏肩后），缓慢推近；保持不变：两人站位、护栏位置。

### 样例 S2：同场景 3 镜头（入场 + 跟拍 + 对峙）

- 场景：白天废弃仓库，钢架货架两排，地面浮尘，天窗自然光。
- 人物 1：苏晴，女，25 岁，马尾，红色连帽衫、牛仔裤。
- 人物 2：老周，男，50 岁，灰白寸头，灰色夹克。
- 画幅 16:9，24fps，每镜头单连续机位，总长 30 秒（12+10+8，各在 5-15 秒内），同一场景连续时间。固定项按对象/时段显式区分"位置固定"与"允许动作变化"：
  1. 镜头 1（人物入场，12 秒）：老周从仓库侧门走入，停在货架口张望；固定机位中景。位置固定：侧门、货架排布、天窗光线。动作变化：老周由门口走到货架口，镜头末态为老周站定于货架口。
  2. 镜头 2（跟拍，10 秒）：苏晴抱纸箱从通道远端走向老周，距离逐渐缩短；机位跟随平移。位置固定：老周站位（承接镜头 1 末态，仍在货架口）、通道方向与货架排布、白天光线时段。动作变化：仅苏晴位置随走动接近，镜头内不落定终位。
  3. 镜头 3（简单对峙，8 秒）：承接镜头 2 末态，苏晴行至老周前约两米站定、放下纸箱，老周抬手示意；单机位缓推正面双人中景。位置固定：环境道具（货架、通道、天窗光线）与两人对峙时约两米距离。动作变化：纸箱随"放下"动作由苏晴手中移至地面，起止状态明确（起：手中；止：地面）。

### 样例 S3：缺失输入样例（结构化缺失，不编造）

- 用户仅输入："两人在咖啡店对话，10 秒。"
- 系统返回结构化缺失清单，要求补全后重试，不代填、不虚构：
  1. 人物身份与外观：姓名/年龄段/性别、发型、服装（套件需要稳定的 roleId 与外观）。
  2. 环境细节：店内布局、时段与光线、桌面陈设。
  3. 机位意图：景别、角度、运镜方式，或选择"由模板默认"。
  4. （若选拆镜）场景范围确认：单镜头即可，还是同场景多镜头。
- 缺失项补齐前不生成计划；mock 与真实路径同样不编造身份、外观或资产。

## 4. 模型、凭据与权限预算（A3）

- 默认 mock：确定性输出并明确标识模拟模式；未配置真实模型时全部确定性功能可用，不因模型缺位阻塞。
- 单 chat 适配路径：预留一个 OpenAI-compatible chat 工作流适配路径；本轮真实 endpoint 与 model 均未指定、未配置。未实测任何供应商，不声称兼容性。
- 真实模型预算为 0：指产品运行时本轮不发生任何真实模型消费。该预算不涵盖已获授权的开发代理调用（planner/coder/reviewer 本轮正常工作），也不构成对当前编码工具使用的限制。
- 凭据边界：密钥只能经用户显式触发的主进程剪贴板导入；禁止后台读取剪贴板；不自动修改剪贴板内容；renderer 仅接收"是否已配置"状态，不接触密钥明文；安全存储不可用时仅存内存，不写盘、不入日志。
- 调用预算上限（后续 007/016 实现，此处为冻结值）：计划阶段最多 2 次请求；每镜头 1 次初稿 + 最多 2 次修复；5 镜头单次流程最多 17 次；另设 token 与总时长上限，最先达到者生效；usage 缺失记 `unknown`，不算零消费，不确定结果不自动重发。
