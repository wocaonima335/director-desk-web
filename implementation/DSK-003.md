### 1.1 共享契约层 `shared/contracts/`（A1、A2；全部新增，纯模块：无 DOM/Electron/Node 依赖）

| 文件 | 内容 |
|---|---|
| `version.ts` | 冻结版本常量 `dsk.v1` |

| `index.ts` | 公共出口 |

契约覆盖：StorySpec（含 5-15s/15-75s、3-5 镜头、角色去重、24fps 帧对齐跨字段校验）、ShotPlan（总长=镜头和、多镜头 3-5、1 镜头 5-15、shotId/entityId 去重、roles 必须覆盖 roleIds）、ModelShotProposal（模型唯一可产出形态：仅套件/语义参数）、CompiledShotProposal（仅确定性编译器可署名，操作复用引擎 EditOperation 形状）、WorkflowState/Event（stage/事件类型封闭枚举、seq≥1、事件带 workflow/step/request 标识）、Approval（绑定 scopeHash/planHash/有限预算；plan 审批必须携带 planHash，export 不得携带）、SnapshotRef（不透明句柄，含 path 即拒绝）、ProviderRequest/Response/Usage（usage `known:false` 时禁止伪造计数含 0；unknown 响应禁止携带内容/声明 usage 已知；timeoutMs 1s-120s）、错误码封闭集合（UNTRUSTED_SENDER / UNKNOWN_VERSION / INVALID_ACTION / INVALID_PAYLOAD / PAYLOAD_TOO_LARGE / NOT_IMPLEMENTED / ACTION_FAILED）。

roleId（选角稳定身份，小写+连字符）与 entityId（每镜头引擎实例，字母开头含下划线）为不同品牌化字符串类型，词法空间不同且互不可换（fixture 与编译期双重保证）。

## 2. prepare-desktop.mjs 为什么零修改

任务单允许修改该文件，但实施发现无需修改：`integration.cjs` 的既有 esbuild bundle 步骤（`bundle: true`）自动内联其 require 的 `../shared/contracts/index.ts` 及 zod；第三方许可清单经既有 metafile 扫描自动收录 zod（staged `THIRD-PARTY-LICENSES.txt` 已含 zod 条目）；`check-release-privacy.mjs --desktop` 本就扫描 staged `integration.cjs`，因此打包后的契约代码仍受隐私规则覆盖，未新增未扫描产物。打包前已用探针验证"esbuild 从 CJS 入口打包 TS+zod"可行（探针已清理）。
